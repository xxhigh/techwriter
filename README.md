# techwriter

티스토리 기술 블로그 글쓰기 스킬입니다. 한국어 기술 문서 스타일 가이드, 글 유형별 템플릿, 티스토리 코드 블록 가이드, 발행 전 체크리스트, 형식 검사 스크립트로 구성되어 있습니다.

## 구성

```
skills/techwriter/
├── SKILL.md                    # 워크플로우(기획 → 초안 → 교정 → 최적화 → 자체 평가)와 규칙
├── references/
│   ├── style-guide.md          # 한국어 기술 문서 스타일 가이드
│   ├── templates.md            # TIL / 튜토리얼 / 트러블슈팅 / 딥다이브 / 회고 / 비교 분석 템플릿
│   └── code-blocks.md          # 티스토리 코드 블록 작성 가이드
├── assets/post-checklist.md    # 발행 전 체크리스트
└── scripts/check-post.js       # 형식 검사 (제목·태그·메타 설명·문장 길이·문체·placeholder)
```

형식 검사는 Node만 있으면 실행됩니다.

```
node skills/techwriter/scripts/check-post.js <글.md>
```

## 효과 측정: 스킬 v3 vs 스킬 없음

같은 요청 4개(TIL, 튜토리얼, 트러블슈팅, 비교 분석)를 각 2회씩, 스킬을 쓴 경우와 안 쓴 경우로 나눠 생성했습니다. 실행 모델은 양쪽 모두 Claude Sonnet이고, 두 조건 모두 "결과를 .md 파일로 저장"만 지시했습니다. 조건당 8편입니다.

### 규칙 준수율 (자동 채점)

스킬의 style-guide와 체크리스트에서 기계로 검사할 수 있는 15개 규칙을 뽑아 정규식으로 채점했습니다.

| 항목 | 스킬 v3 | 스킬 없음 |
|---|---|---|
| frontmatter(title, category, tags, description) | 100% | 0% |
| 메타 설명 150자 이내 | 100% | 0% |
| 태그 5~10개 | 100% | 0% |
| 제목 30~50자 | 100% | 25% |
| 모든 코드 블록에 언어 명시 | 100% | 63% |
| 이중 피동(되어지다) 없음 | 100% | 100% |
| 1인칭(저는/제가) 없음 | 100% | 100% |
| ~것 같습니다 없음 | 100% | 88% |
| ~해주다 없음 | 100% | 75% |
| 비권장 용어 표기 없음 | 100% | 100% |
| 40자 이하 문장 80% 이상 | 100% | 13% |
| 합니다체/하세요 90% 이상 | 100% | 38% |
| 외부 참고 링크 1개 이상 | 88% | 25% |
| 마무리 섹션 있음 | 100% | 100% |
| 파일에 본문만 (평가표·메모 없음) | 100% | 100% |
| **전체 (15항목 평균)** | **99%** | **55%** |

처음 3개 항목(frontmatter, 메타 설명, 태그)은 스킬 없이는 지시 자체가 없어 0%가 당연합니다. 그 3개를 빼도 v3 99%, 스킬 없음 69%입니다.

### 읽는 법

- **스킬이 바꾸는 것은 문체와 발행 준비입니다.** 스킬 없이는 8편 중 5편이 해라체·해요체로 나왔고, frontmatter·메타 설명·참고 링크가 거의 없었습니다.
- **기술 정확성은 같습니다.** 스킬은 정확성을 올리지 않습니다.
- **내용 깊이는 스킬 없는 쪽이 높습니다.** 스킬은 문장을 짧게 쓰고 사용자가 주지 않은 사실을 지어내지 않게 하는데, 그 대가로 글이 약간 얇아집니다. 스킬 없음이 이긴 2판 모두 이 이유였고, 둘 다 판정 신뢰도 "low"였습니다.
- **비용.** 스킬은 참조 문서를 읽고 검사 스크립트를 돌리므로 실행 시간 약 20%, 토큰 약 30%가 더 듭니다.

### 한계

- 조건당 8편이라 ±10%p 정도는 노이즈입니다.
- 판정자는 LLM이고 8건 중 4건이 신뢰도 "low"입니다.
- 기준선이 "아무 지시 없음"이라, "합니다체로 써줘" 한 줄만 붙여도 격차의 상당 부분이 사라질 수 있습니다. 스킬의 가치는 그 지시들을 매번 안 써도 된다는 데 있습니다.
- 스킬 없음 글은 v1 평가 때 생성한 것이고 v3 글은 v3 평가 때 생성한 것입니다. 요청과 모델은 같지만 생성 시점이 다릅니다. 블라인드 판정은 이 두 묶음을 직접 짝지어 수행했습니다.

평가 스크립트와 원문은 저장소에 포함하지 않았습니다.
