# Tech Blog Writer

A Codex plugin that turns development notes,
code snippets, debugging logs, and technical research
into structured developer-focused blog posts.

## Features

- Turn rough development notes into articles
- Structure debugging stories
- Explain code in context
- Preserve technical reasoning
- Review technical claims
- Improve existing drafts

## Installation

```bash
codex plugin marketplace add hong/tech-blog-tools
codex plugin add tech-blog-writer@hong-tools
```
